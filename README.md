# NOTED

React Native Expo notes app scaffolded with the Axix Teacher App architectural pattern:

- `app/` for Expo Router routes
- `src/screens/` for screen-level UI
- `src/components/` for reusable presentation components
- `src/hooks/`, `src/services/`, `src/constants/`, and `src/utils/` for shared app logic

## Run

```bash
npm install
npm run start
```
